## What Is ZKA Labs

ZKA Labs is the digital headquarters of the ZKA ecosystem. It is the organizational layer that connects, operates, and observes every component in the system.

ZKA Labs is not a product. It is the command center.

## Ecosystem Architecture

```
ZKA (identity)
└── ZKA Labs (digital headquarters)
    ├── AI Observatory    — Intelligence Layer
    ├── ZKA Model         — Model Layer
    └── ZKA Playground    — Creative Layer
```

| Component | Role | Status |
|-----------|------|--------|
| [AI Observatory](https://zeroknowledge0x.github.io/ZKA-Labs/#observatory) | Intelligence Layer — observes the global AI ecosystem through model catalogs, provider activity, and capability mapping | Live |
| [ZKA Model](https://zeroknowledge0x.github.io/zka-model/) | Model Layer — unified API access to ZK AI models, OpenAI-compatible | Live |
| [ZKA Playground](https://zeroknowledge0x.github.io/zka-playground/) | Creative Layer — build, test, preview websites from AI-generated code | Live |

## What's Inside

### AI Observatory
A living map of the global AI provider landscape. Pulls real-time data from the OpenRouter catalog — models, providers, context windows, open-source ratios. Rendered as an interactive canvas with hover exploration.

### Operating Doctrine
Five principles that govern how ZKA Labs operates:
1. ZKA is the identity
2. ZKA Labs is the organization
3. Every component has a clear role
4. Research and infrastructure are one layer
5. Built in public, operated with discipline

### Research Streams
- **Intelligence Gathering** — mapping the global AI ecosystem
- **Model Infrastructure** — unified API access, routing, inference optimization
- **Creative Systems** — AI-powered code generation and web app building
- **Future Exploration** — new systems from real research and operational needs
